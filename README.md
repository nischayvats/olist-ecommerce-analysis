# Olist Brazilian E-Commerce Analysis

End-to-end data analytics project on 100,000 real e-commerce orders from Olist (2016–2018).

## 🔗 Live Dashboard
[View Interactive Dashboard](https://nischayvats.github.io/olist-ecommerce-analysis/olist_dashboard.html)

## Project Overview
Analysed 1.5M+ rows across 8 related tables to uncover customer behaviour, revenue trends, seller performance, and RFM segmentation insights.

## Key Findings
- **97% of customers never made a second purchase** — major retention problem
- **Delivery speed drives reviews** — 1-star orders take 20.8 days vs 10.2 days for 5-star
- **São Paulo = 42% of all orders** — geographic concentration risk
- **Black Friday 2017 peak** — 7,274 orders in one month, 22x growth in 13 months
- **At Risk segment = R$3.7M revenue** — highest priority for win-back campaigns

## Tech Stack
- **MySQL** — database design, 8 tables, 1.5M+ rows
- **SQL** — 20 queries including window functions, CTEs, RFM segmentation
- **Python** — pandas, matplotlib, seaborn (Jupyter notebook)
- **HTML/JS/Chart.js** — interactive 4-page dashboard
